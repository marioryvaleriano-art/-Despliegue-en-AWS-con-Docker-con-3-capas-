Estructuración de contenido para el archivo README.md

En esta etapa se realizó la definición de la estructura base del archivo README.md del repositorio del proyecto Bodega Peirano.
El objetivo principal de este archivo es brindar una explicación general del sistema, facilitar su comprensión y permitir que cualquier desarrollador pueda instalar, ejecutar y entender el proyecto de manera rápida.

Para ello, se establecieron las secciones obligatorias que conformarán la documentación inicial del repositorio.

Las secciones definidas fueron las siguientes:

Nombre del Integrante
Mariory Valeriano de la Cruz
Descripción del proyecto
Sección donde se explica el propósito del sistema, sus funcionalidades principales y el objetivo de negocio que busca resolver.
Tecnologías utilizadas
Espacio destinado a documentar todas las tecnologías, frameworks y herramientas utilizadas durante el desarrollo del sistema, tales como Angular, Spring Boot, SQL Server y Docker.
Pasos de despliegue
Contiene las instrucciones necesarias para instalar, configurar y ejecutar el sistema correctamente en un entorno servidor o local.
Comandos Docker utilizados
Sección enfocada en documentar los principales comandos Docker empleados para crear, ejecutar, administrar y monitorear los contenedores del proyecto.
Evidencia de funcionamiento
Apartado destinado a incluir capturas de pantalla, pruebas del sistema o evidencias visuales que demuestren el correcto funcionamiento de la aplicación.
